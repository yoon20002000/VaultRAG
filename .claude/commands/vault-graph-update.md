# /vault-graph-update — graphify vault 그래프 즉시 갱신

`vault/` 폴더의 최근 변경사항을 graphify 지식그래프(`graphify-out/graph.json`)에 반영한다.
매번 `/graphify vault --update` 를 직접 치는 대신 한 번에 부르기 위한 단축 커맨드다.
`vault-sync`가 세션 종료 시점에 y/n으로 물어보는 것과 별개로, 세션 도중 아무 때나 즉시 갱신하고 싶을 때 쓴다.

## 작업 순서

0. **실행 위치와 인자 (필수)** — 둘은 서로 다른 것을 정한다. 헷갈리면 사고가 난다.

   | | 정하는 것 | 지켜야 할 값 |
   |---|---|---|
   | **인자** | **무엇을 인덱싱할지** | 반드시 `vault` — `.` 나 인자 생략은 **저장소 전체(코드 포함)를 인덱싱한다** |
   | **cwd** | 산출물이 떨어질 위치 | 반드시 **저장소 루트** |

   - 인자가 `vault` 이면 저장소 루트에서 실행해도 코드는 들어가지 않는다.
   - cwd 가 다르면 그 위치에 별개 그래프가 통째로 생긴다 (`vault/graphify-out/` 이 그렇게 만들어진다).
     `graph.json` 뿐 아니라 `.graphify_incremental.json` 등 스크래치 파일도 전부 cwd 에 떨어진다.

1. **선행 확인**: `graphify-out/graph.json` 존재 여부 확인.
   - 없으면 실행하지 말고 "graph.json이 없습니다 — `/graphify vault` 로 최초 생성을 먼저 하세요"라고 안내한 뒤 종료.
2. **실행 전 안내**: vault 문서 변경분이 있으면 semantic 추출(서브에이전트)이 돌아 다소 시간이 걸릴 수 있음을 한 줄로 미리 알린다.
3. **실행**: `Skill(skill="graphify", args="vault --update")` 호출.
   - 변경 파일이 전혀 없으면 graphify가 "No files changed since last run"류 메시지를 반환 — 그대로 전달하고 종료.
4. **결과 보고**: graphify가 반환한 변경량(신규/변경 노드·엣지 수)과 이번 실행 토큰 비용을 요약해서 보여준다.

## `--update` 는 치환이 아니라 누적이다

`--update` 는 변경된 문서를 **다시 추출해 얹을 뿐, 그 파일의 옛 노드를 지우지 않는다.**
같은 문서를 여러 번 갱신하면 노드가 크게 불어나고, 같은 개념이 id 규칙이 회차마다 달라 여러 노드로 공존할 수 있다.
회차가 쌓이면 옛 서술이 최신 서술을 **물량으로 이겨** 질의 결과가 낡아진다.

- 감사: `python .claude/scripts/graphify_audit.py`
  → 좀비(사라진 source_file) · 누적층(그래프 노드 > 최신 추출) · 라벨 중복 · 얕은 추출을 계량한다.
- 누적은 `--update` 로 절대 줄지 않는다. 줄이려면 **전체 재빌드** 뿐이다:
  `graphify-out/{graph.json,manifest.json}` 을 백업 후 삭제하고 `cache/` 를 옮긴 다음
  (캐시를 남기면 옛 노드가 캐시 히트로 다시 들어온다) `/graphify vault` 를 인자 없이 돌린다.
- 재빌드 직후 감사에서 좀비 0 · 라벨 중복 최소를 확인한다. exit 0 은 성공 근거가 아니다.

## 주의

- **job 문서는 이동하지 않는다.** 완료는 frontmatter `status` 로만 표시한다 —
  경로가 바뀌면 옛 경로 노드가 그래프에 화석으로 남는다.
- **graphify 대상은 `vault/` 뿐이다.** 프로젝트 코드 그래프는 만들지 않는다.
- 산출물은 **저장소 루트의 `graphify-out/`** 하나만 유지한다. vault 안에는 지식 `.md` 만 둔다.
- `vault-sync` 종료 시 갱신 여부를 `n`으로 거절했더라도, 이 커맨드로 언제든 나중에 수동 갱신할 수 있다.
- 자동으로 반복 실행되지 않는다 — 항상 사용자가 명시적으로 호출했을 때만 동작.
